## Findings

### M1（Major）: 「組み合わせられないという inferred の信念」の規則が、dd を矢印の言い直しの型にそろえ、述べられた制約も推測に落とす

- 根拠:
  - `cloud-system.txt:25` は「述べた制約が無く、2 案が組み合わせられそうに見えるときの dd は『両方を組み合わせることはできない』という inferred の信念にし」とする。
    この文は dd の矢印「d と d2 は両立しない」の言い直しで、同じプロンプトの「前提にしないもの:『どちらか一方を選ばなければならない』『同時にはできない』」と、
    ADR 0006 §5 の「前提は『…だから』の『…』にあたる」に反する。r1 の判定の基準（dd の統一規則）でも F の型にあたる。
  - spike r6（このヘッド）を数えると、dd 66 件中 53 件が「組み合わせ／併用／両方を」の型。r5 は 10 件だった。理由を書かない言い直しがそのまま出ている。
    例:「録音画面と診断一覧は役割を分けて組み合わせることができず、警告の出し先は片方に絞るしかないから」（design/i-notice run1）、
    「1人承認の速さと2人で確認する慎重さは、1つの承認ルールには組み合わせられないから」（m1/g4 run3）。
    r4 の定型文（50/66）と同じく、1 つの型が dd を占めている。
  - 述べられた制約よりこの規則が先に効いている。`m2/g3` の dd は、r5 では 3 回中 2 回が u119「人が全然足りない」を grounds に持つ stated だった。
    r6 では 3 回とも同じ中身（「人手の足りない基盤チーム」）を書きながら inferred で、「組み合わせ」の型になった。画面では「推測: 会議では述べられていない」と誤って出る（§1）。
    `e2e-design/i-notice` の u115（同じ欄）は r5・r6 とも使われていない。
  - 打ち手に「組み合わせる」やり方を書くこと自体は、前提を偽にする変更としてよい。問題は dd の本文の型。
- 修正案: この規則を外す。残すなら、「組み合わせられない理由（何がそれを妨げるか）を信念として書く。『組み合わせられない』だけの文にしない」と書き、
  「述べた制約がある場合はこの規則を使わない」と優先を明記する。そのうえで、`m2/g3` と `i-notice` の dd の basis を spike で確かめる。

### M2（Major）: stated の根拠の例が、spike の会議の発話そのままで、その候補の答えになっている

- 根拠: `cloud-system.txt:45` の例「受け口は溢れます」「メモリがじわじわ増えます」は、design（`e2e-design`・`apps/e2e-scripted/scenarios/design` も同じ）の
  u40「そこで待っても受け口は溢れます」と u34「それはメモリがじわじわ増えますね」の写し。
  r4 の JUDGE.md（135 行目）が、`design/i2`・`e2e-design/i2` で B・C を inferred にした誤り（5 回と 6 回）の根拠として挙げた発話そのもの。
  round 1 の M1 と同じ種類の汚染で、今回は言い換えでもない。r6 で B・C の inferred は 10/132（r5 は 38）に減っているが、その一部はこの 2 候補の答えを教えた結果で、測り直しの判定を信用できなくする。
- 修正案: 例を料理の題材の作り話にする（例:「それだと鍋が吹きこぼれます」）。その後で r7 を測るか、`design/i2`・`e2e-design/i2` を除いた数も出す。

### m9（Minor）: 「反対の理由は少なくとも 1 件の前提に使う」が、件数の上限と 2 段目の反対を考えていない

- 根拠: `cloud-system.txt:24`。同じ側への反対が 3 件以上あると、cd（または bd）の上限 2 件に収まらない。検証は 3 件目以降を出てきた順に黙って落とす。
  また、入力の objects_to には理由への反対（2 段目、target が argument）も入るが、置き場所は d・d2 への反論しか書かれていない。
  「その矢印の理由が書けなければ出さない」とも食い違い、理由にならない反対まで前提にさせうる。
  r6 では、上限の 2 件に達した矢印が 19 か所（r5 は 7 か所）に増えた。今回の出力では上限を超えたものは無い（raw の 66 件を数えた。SUMMARY の dropped も 0）。
- 修正案: 「同じ矢印の 2 件まで、全体で 8 件までの中で使う。収まらなければ、前提の理由になる反対から選ぶ」と書く。2 段目の反対は、付いている理由の側の矢印に置くと明記する。
